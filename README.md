# Iron Throne: Zombie Siege

Ein 3D-Top-down-Arcade-Spiel im Browser: Ein bewaffneter Rollstuhl verteidigt eine alte Burg gegen immer stärkere Zombie-Wellen.

## Steuerung

- Desktop: WASD oder Pfeiltasten zum Fahren, Maus zum Zielen und Schießen.
- Smartphone: Linker Joystick zum Fahren, rechter Joystick zum Zielen und Schießen.

Zwischen den Wellen können Waffe, Panzerung, Leben und Geschwindigkeit verbessert werden.
